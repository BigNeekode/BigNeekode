## About Me


Most of my work sits somewhere between **game systems**, **tooling**, and **UX**. I like reusable architecture, fast iteration loops, local-first tools, dense developer interfaces, and systems that stay understandable after the prototype stops being a prototype.

I also make music and sound for games, so the two kinds of keyboard tend to share the same desk.

## Featured Work

<table>
<tr>
<td width="50%" valign="top">

### 🎼 [Serenade](https://github.com/BigNeekode/Serenade)

**A control room for your AI software team.**

A free, local-first desktop GUI for [Secondhand (`hand`)](https://github.com/atqamz/hand). It turns multi-agent coding fleets into something visible and operable: projects, tasks, workers, worktrees, reports, routes, provider state, and supervisor-driven task proposals.

`Tauri 2` `Rust` `React` `TypeScript` `Vite`

</td>
<td width="50%" valign="top">

### 🔨 [Forge Toolkit](https://github.com/BigNeekode/JamForge)

A reusable **Unity 6 toolkit for game jams and prototypes**.

It contains **JamForge** for getting playable quickly and **PolishForge** for feedback, game feel, presentation, and accessibility-oriented polish without dragging a production-sized framework into a jam.

`Unity 6` `C#` `UPM` `Game Tools`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 👁️ [SPreview](https://github.com/BigNeekode/SPreview)

A **VS Code extension for previewing Svelte CEF interfaces** used in game mod development.

Includes live preview workflows and mocks for APIs commonly used by **FiveM / RedM, RAGE:MP, and alt:V**, making game UI iteration possible without constantly jumping back into the game client.

`VS Code` `Svelte` `JavaScript` `CEF` `FiveM`

</td>
<td width="50%" valign="top">

### ⚡ [PowershellAing](https://github.com/BigNeekode/PowershellAing)

A lightweight PowerShell profile built around **fast startup and practical developer ergonomics**.

Git-aware prompt, navigation helpers, lazy-loaded modules, remote detection, shortcuts, and a deliberately small startup footprint.

`PowerShell` `Git` `Developer UX`

</td>
</tr>
